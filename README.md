## Техническое задание

3D puzzle / exploration игра, в которой игрок исследует тёмный комплекс, ориентируется с помощью эхолокации и проходит уровень, используя временное проявление окружения и реакцию объектов на звуковой импульс. Для визуального и технического оформления будут применяться VFX Graph, post-processing / emission, baked lighting и Cinemachine.

1. Будет реализован эхолокационный импульс: игрок сможет выпускать волну, которая на короткое время проявляет геометрию уровня, скрытые платформы, двери и опасные зоны в почти полностью тёмном окружении. Визуал импульса будет выполнен через VFX Graph, с использованием post-processing и emission для эффекта кратковременного "проявления" мира.

2. Будет реализовано звуковое взаимодействие с миром: одни объекты будут активироваться от импульса, а другие - становиться опасными или временно менять своё состояние после "пробуждения" звуком. Для усиления атмосферы будут использоваться baked light, а также Cinemachine для акцента камеры в момент выпуска импульса.

## Как реализовано

Проект находится в `EchoPulse`. Основная сцена: `EchoPulse/Assets/Scenes/SampleScene.unity`.

В сцене собран first-person walk-only прототип тёмного комплекса. Игрок ходит по уровню, выпускает эхолокационный импульс и на несколько секунд видит скрытую геометрию, мосты, двери, опасные зоны и финишный маяк. Уровень расширен второй секцией с L-образным поворотом, скрытым мостом, второй дверью, второй опасной платформой и финальным тоннелем.

Используются:

- URP post-processing и emission-материалы для временного проявления объектов.
- VFX Graph hook `EchoPulse_EchoWave.vfx` и fallback-визуал через `LineRenderer`.
- Cinemachine camera/FOV kick при выпуске импульса.
- Baked lighting и слабые route lights для атмосферы.

Управление:

- `WASD` или стрелки - ходьба.
- Мышь - обзор.
- `Left Mouse` или `Enter` - эхолокационный импульс.

## Основные скрипты

- `FirstPersonWalkController.cs` - простое first-person управление без прыжка и спринта, reset игрока на spawn.
- `EchoPulseEmitter.cs` - выпуск импульса, cooldown, поиск реактивных объектов через `Physics.OverlapSphere`, VFX/fallback-визуал, Bloom/FOV/light kick.
- `EchoPulseReactive.cs` - базовый абстрактный класс для объектов, реагирующих на импульс.
- `EchoRevealable.cs` - временно проявляет скрытую геометрию и материалы уровня после импульса.
- `EchoDoor.cs` - дверь, которая открывается от импульса, остаётся физически открытой несколько секунд и затем закрывается.
- `SoundHazard.cs` - опасная зона, которая просыпается от импульса и reset-ит игрока при касании.
- `FinishTrigger.cs` - завершение уровня при входе игрока в финальный trigger.
- `LevelGoal.cs` - хранит состояние завершения и показывает сообщение в Game View.
